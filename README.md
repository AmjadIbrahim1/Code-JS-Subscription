## 📌 Project Overview

**Code-JS Subscription** is a static landing page designed to promote and manage subscriptions for the **Code-JS programming course**. The page presents the course roadmap, showcases student reviews, and provides a clear call-to-action for joining the course through the associated Telegram bot.

---

## ✨ Key Features

- 🗺️ **Course Roadmap** – Visual roadmap image explaining the learning path
- 💬 **Student Reviews** – Testimonials section ("اراء الطلاب") showcasing learner feedback
- 📦 **Course Content** – Organized section listing the course curriculum ("محتويات الكورس")
- 🤖 **Telegram Bot Integration** – Promotes the course bot for enrollment and support
- 🎨 **Clean Static Design** – Pure HTML/CSS with no build tools required

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/AmjadIbrahim1/Code-JS-Subscription.git
   ```
2. Open `index.html` in any modern web browser.
3. No server or build step required — the page works fully offline.
